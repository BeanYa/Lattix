# Lattix 液态玻璃风 Dashboard 原型

单文件静态原型（`index.html`，无构建、无依赖），按「目标导向 Dashboard」布局
提示词构建：左侧导航栏；主区上方大标题 + 进度条突出今日核心目标（出站流量
1 TB）；目标下方一行快捷操作入口（添加服务器 / 创建链路 / 新建用户 /
重新生成订阅 / 运行测速）；右侧 AI 助手模块（建议芯片 + 对话输入）；底部
跨统计区域支持日/周切换，出站、入站、峰值带宽、活跃连接四项柔和色块指标与
趋势图表同步更新。整体沿用液态玻璃底座与六种交互动效，**主题为深色**：暖黑晚霞渐变背景
（左上铜色光晕 + 两道微光弧），深色磨砂玻璃卡（细白描边 + 顶部内高光），
铜橙亮色 `#E2A57B` 作当前项/标签强调，`#E7A471→#C5A0AB` 渐变图表，
进度条带铜色辉光；toast 与 dock 名称气泡反转为浅奶油底以保证对比度。

原型只展示页面构建后的大体效果：**不含登录/鉴权流程，不接入任何后端或真实数据**。
页面里的数字（6 台服务器、5 条链路、1284 用户等）全部是写死的示意占位值——取值时
参考了仓库自带演示数据 `src/frontend/src/lib/dashboard-demo.ts` 的结构和命名，只是
为了让画面接近真实使用形态，不代表任何真实系统；页面与模块词汇来自 `docs/design/`。

## 打开方式

```bash
cd prototypes/glass-dashboard
python3 -m http.server 4173
# 浏览器访问 http://127.0.0.1:4173/
```

直接双击 `index.html` 也能运行（字体走 Google Fonts CDN，离线时回退系统字体）。

## 视觉底座（按提示词规格）

- 背景：`#E4C0A6`（左上暖桃）→ `#D4B8AC`（灰粉）→ `#EBD7CC`（浅杏）三段径向渐变，
  叠两道白色半透明光弧。
- 玻璃卡：`backdrop-filter: blur(28px) saturate(140%)`，白色 44%–66% 透明度，
  1px 半透明白描边，顶部内侧 1px 高光，圆角 24px（主面板）/18px（内部模块），大而柔的阴影。
- 层级：主面板一层玻璃 → 内部模块再叠一层；榜单 `#F3F1F1` 实底；
  链路健康为 `#1B1B19` 深色卡，顶部铜色光晕。
- 强调色：铜橙 `#B66D44`（当前项/标签/活跃链路章），图表渐变 `#E7A471 → #C5A0AB`，
  榜单未达成部分浅灰半透明轨道。
- 字体：Manrope（回退 Plus Jakarta Sans / PingFang SC），页面大标题 48px，
  全部数字 `font-variant-numeric: tabular-nums`。

非仪表盘页面为占位视图，用于验证导航手感；真实布局以 `docs/design/` 系列稿为准。

## 实现注记

- 模块放大/收回采用 **transform 合成器 FLIP**（translate+scale），
  布局属性只在起止各设置一次——Chrome 对 `left/width` 逐帧动画会留下脏的 grid 轨道
  状态（fr 列被永久撑爆），transform 路径绕开该问题且更流畅。
- metaball 分裂用 SVG `feGaussianBlur + feColorMatrix` goo 滤镜作用于胶囊形层，
  文字层独立不受滤镜模糊影响；收起态用 `visibility` + `pointer-events` 屏蔽
  不可见选项的命中与滚动溢出。
- 尊重 `prefers-reduced-motion`：全部动效降级为瞬时切换；触屏不启用追光倾斜与 dock 放大。

## 已知边界

- 所有数据为前端写死的示意值（除时间筛选的联动演示外均为静态），非真实统计口径。
- 不包含登录页与任何鉴权/后端交互。
- 占位页（运行监控、用户等）仅为导航验证，不代表最终布局。
