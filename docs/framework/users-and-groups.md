# 用户、链路与可见性

## 订阅可见性

- 订阅页的「链路可见性」与面板的「访问 → 可见性管理」编辑同一份用户隐藏名单。默认显示所有可用的已发布面板链路、用户已有的独立节点和全部外部订阅。
- 隐藏名单以 `chain:<id>`、`node:<id>`、`external:<id>` 区分来源。链路改名沿用同一个 ID，新建链路默认显示。暂时不可用的已隐藏条目保留原选择。
- 每个外部订阅有一个开关，可展开预览子节点。隐藏后，该来源的节点整体从各格式快照移除。
- 用户与管理员的可见性保存、用户的模板保存和恢复默认进入同一个按用户排序的持久化队列。每个成功任务原子提交设置和全部格式快照，并提供独立的完成状态。失败会保留上次成功的交付，队列继续处理后续请求。
- 链路分组用于面板内组织链路和外部订阅。旧用户分组入口转至可见性管理。迁移保留先前已发放的链路凭据及已生效的外部流量合并方式。

## 链路凭据与停权

- 面板以已发布修订确定订阅入口。共享入口链每个用户和每条链有稳定的访问凭据。独立节点和普通出口使用用户 UUID。
- 隐藏仅控制订阅输出。用户停用、到期、配额用尽或尚未生效时，由既有生命周期停权逻辑同步节点与共享端点凭据。
- 新用户及新发布链路使用相同的凭据同步路径。Agent 首次连接到重启后的面板时，已有链路补发目录凭据。
