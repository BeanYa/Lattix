# 节点编排模板与创建期编排设计

## 已确认需求

- 链路页下方新增“节点编排模板”，支持命名、创建、编辑和复用一组服务器及其触发动作。
- 沿用现有编排器画布功能与样式。新建模板画布为空，提示选择根服务器；选择后加入根节点。
- 模板初始不预填地址和端口。地址留待链路实例填写；端口初始为 0（自动），用户也可在模板中填写具体默认端口。
- 链路编辑器左侧服务器导航新增“自动编排模板”标签页，支持拖入模板，带入主选服务器、候选和编排动作，再在链路编排编辑器完成实例参数。
- 创建链路时卡片上方的自动编排入口可直接使用，无需先保存链路。
- 模板默认共享：编辑模板会同步关联实例；提供“另存为独立副本”，分离后不再跟随原模板。
- 共享模板后续修改端口时，仅更新尚未单独修改的实例参数；实例自行填写的值保留。

## 交互流程

### 模板管理

“节点编排模板”放在链路页列表下方，每项显示名称、主选服务器、服务器/触发器数量和引用链路数，可新建、编辑、重命名、另存为新模板或删除。

新建时先展示空画布和选择根服务器提示。选择后成为“主选”，按既有流程添加“备选”、触发器及连线。端口初始为 0，代表自动分配；可设置具体默认端口。模板不携带任何运行态、切换历史或具体链路的地址绑定。

### 应用到链路

左侧标签页为“服务器”和“自动编排模板”。模板可拖入或点击添加，画布生成该模板主选服务器卡片，并携带完整编排草稿。模板名称、共享状态及配置入口在该卡片上可见。地址留空，端口取模板默认值（含 0）。

新建与编辑链路均可立即打开编排器。应用编排先写入向导草稿，最终与链路创建/编辑一起提交；取消向导不产生后台图配置副作用。最终跳序由画布路径计算，不依赖旧服务器快照。

### 共享与独立

关联模板的实例允许填写本链路的地址、端口，每项显示继承/已覆盖状态，并可恢复继承。只有确实修改的参数成为覆盖；显式填写 0 是有效覆盖，不能误当成“未填写”。

编辑共享动作使用“编辑共享模板”，明确提示将影响其他关联链路；不把实例内的普通参数输入隐式写回共享模板。需要独立修改服务器、动作或优先级时，选择“另存为独立副本”，以当前解析出的完整图和参数落地并解除关联。

共享模板保存前显示受影响链路数量与需重新部署的跳位。变更影响当前生效节点的地址/端口时，复用现有修订部署流程；仅修改候选或触发动作时，不进行无关部署。

## 数据模型与同步

新增持久化模板表，包含 id、name、revision、graph_json 与时间戳。图复用现有 nodes/edges 结构，服务器以真实 server_id 引用。模板根一经选定不能被普通删除操作移除，换根通过另建模板完成。

关联表按 chain_id + seq 保存 template_id、已同步 revision、参数覆盖以及待同步状态。参数覆盖按 server_id 定位（图中服务器唯一），使用“字段缺省表示继承”的显式模型；address="" 与 listen_port=0 都可作为有效实例设置。

每次解析先取模板，再叠加实例覆盖；“另存为独立副本”保存解析结果并删除关联。模板中的新增服务器先使用模板默认端口和空地址，原有实例覆盖不丢失。

保留现有 chain_hop_graphs 作为运行图，模板更新需校验所有关联跳位后同步生成对应运行图，并持久记录待应用版本。同步由现有每链 worker 串行推进，部署仍走 panel 修订/状态机，重启后可继续；失败写入既有 orchestration_error 并保留现场，不以清空覆盖或偷偷分离实例来“修复”失败。

## 验证与事务

提取现有图形结构校验，供模板与链路共同使用；不另写一套不一致的连线规则。模板编辑允许上一跳/下一跳触发器，实际绑定跳位时校验入口/出口边界、服务器能力和跨跳复用。

创建/编辑链路请求新增可选编排数据，包含 seq、图或模板引用及参数覆盖。字段缺省保持旧请求行为，显式空图表示清除。拓扑与编排在同一既有存储事务中落库，不留下半条链或孤立绑定；编辑继续经过修订与状态机，不绕开部署流程。

保存共享模板前验证所有关联实例：若存在部署中的链路、移除了当前生效服务器、端口不合法或其他拓扑冲突，拒绝本次整体保存并列出关联链路及原因。已填写的实例覆盖不被模板覆盖。删除正在引用的模板时提供引用说明，先分离关联实例为独立图再删除，保护已运行链路。

## 复用与兼容约束

- 复用 requester、API 协议/鉴权/CSRF/幂等、OpenAPI 类型生成、图结构和校验。
- 复用 OrchestrationCanvas、ChainNodeCard、现有编排器操作和链路 canvas reducer；无新增依赖、无另一套画布样式。
- 草稿/模板模式不轮询运行链路，也不调用仅供已保存跳位使用的接口。
- 画布节点持有编排草稿；删除、替换和模板应用通过 reducer；移动不丢失配置。
- 多路径创建按每条路径的实际 seq 映射编排，分别校验。
- Agent 更新分支已合入 main；本工作区已快进至 b5370d8，保留更新中状态、计划内重连与存活 Xray 的既有规则，不自动发布。

## 验收场景

1. 空模板 → 选根 → 配动作与候选 → 命名保存 → 重载保留；默认端口 0，也能保存具体数字。
2. 模板拖入新建链路，未保存链路就可打开编排器，补参数并随创建请求持久保存。
3. 同一共享模板被多条链路使用：未改参数跟随更新，单独设置（含 0）的参数保留；恢复继承后再次跟随。
4. 独立副本分离后不再跟随模板变化；模板另存新项拥有独立身份和名称。
5. 模板新增/删除节点、触发动作或修改默认端口时，关联实例校验、重新部署与失败现场符合约束。
6. 重复服务器、已删服务器、不适用边界触发器、端口越界、非法连线都不能部分保存。
7. 全部前端测试、格式、lint、构建与 Go 测试/静态检查通过；完成浏览器桌面和窄屏验收，最终报告内嵌实际截图，截图不提交。
