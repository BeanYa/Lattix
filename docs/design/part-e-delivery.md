### 10.2 键盘、焦点与朗读

| 按键 | 作用域 | 行为 |
|---|---|---|
| Tab / Shift+Tab | 全局 | 顺序：跳过链接 → 侧栏 → 顶栏 → 主内容；浮层打开时限制在浮层内 |
| ↑ / ↓ | 列表、菜单、命令面板 | 列表用 roving tabindex 移动真实焦点；命令面板移动高亮；Home/End 到首尾 |
| Enter | 行、菜单项、按钮 | 打开检查器/详情；L3 危险提交不响应 Enter，必须显式点击 |
| Space | 复选、行选择 | 切换选中，不滚动页面；表头三态（全选/部分/无） |
| Esc | 最上层浮层 | 关闭检查器/对话框/托盘/命令面板，焦点回触发元素；不关闭页面 |
| ⌘K / Ctrl K | 全局 | 打开命令面板；输入框内同样生效（组合键不违反 2.1.4） |
| / | 主内容聚焦时 | 聚焦当前页搜索框；不在文档级监听，避免误触 |
| Alt+↑ / Alt+↓ | 编排器节点 | 键盘重排，与拖拽等价（2.5.7） |
| PageUp / PageDown | 命令面板、表格 | 翻页/滚动；不与分页按钮抢焦点 |

焦点规则（实现约束）：

1. **焦点环唯一**：`outline: 2px solid var(--panel-focus); outline-offset: 2px`；不在父容器裁切（检查器、表格容器 `overflow` 需留 2px 内距）。
2. **落点**：路由切换后焦点落到新页 h1（`tabIndex={-1}`）并更新 `document.title`；读屏不整页重读，只播报标题。
3. **返回**：检查器/对话框关闭后焦点回触发元素；对象被删除导致触发元素消失时，焦点落到列表容器并播报「对象已删除」。
4. **sticky 遮挡**：所有可聚焦元素 `scroll-margin-block: 96px`；顶栏 56 + 吸顶表头 36 是固定值，不随页面变化。
5. **托盘**：不抢焦点、不设遮罩；卡片状态用 `aria-live="polite"`，失败用 assertive；展开/收起按钮 ≥44×44，Esc 收起并回按钮。
6. **表格行**：整行点击是鼠标便利，键盘用行内「打开」按钮；不把 `<tr>` 改成 `role="button"`，保留表格语义。

朗读与语义：

- 地标：`header` / `nav aria-label="主导航"` / `main` / 检查器 `aside aria-label="服务器检查器"`；现状只有 `main`（`Layout.tsx:287`），其余需补。
- 表格：`<caption class="sr-only">`；数值与单位同一文本节点（「42 位用户」），不拆成两个 span；`tabular-nums` 不影响朗读。
- 状态：状态词固定为「通行 / 部署中 / 降级 / 异常 / 待确认 / 未知」（第 6.2.5 节）；颜色与字形只作加速。
- 图表：canvas `aria-hidden="true"`，同级提供摘要（「过去 24 小时总流量 1.2 TB，峰值 12:00」）与「查看数据表」按钮；不把 canvas 设为可聚焦。
- 拓扑：`<ol aria-label="链路 HK-JP-US 的 3 跳">`，每项文本「02 JP-02 中转 部署中」；连接线 `aria-hidden`。
- 复制：按钮名「复制订阅地址」，成功后 `aria-live` 播报「已复制」，2 秒后清除；不依赖 Toast。
- 时间：`<time datetime>`；时区在页头统一说明，不逐条重复。
- 机器码：代号（L1）、协议（VLESS）、端口（443）加 `lang="en"`；中文标题不做全大写。

### 10.3 减少动效、缩放与对比模式

| 场景 | 默认 | `prefers-reduced-motion: reduce` |
|---|---|---|
| 页面/浮层进入 | 180–240ms，`translateY(8px)` | 直接呈现，仅保留 opacity（≤1ms） |
| 进行中 270° 弧 | 1.2s 线性旋转 | 静态 270° 弧 + 百分比文字 |
| 拓扑线路绘制 | 240ms + 40ms/跳 | 一次呈现，无 dash 动画 |
| 状态切换 | 140ms 字形 cross-fade | 立即替换 |
| 读数更新 | 600ms 背景 flash | 无 flash，数字直接替换 |

- 全局已在 `index.css:531-539` 把动画/过渡压到 `0.01ms`；新组件必须在该规则下仍可读（不靠动画表达状态）。
- 200% 缩放：五档宽度逐页检查；中文实际渲染 ≥24px；表格容器允许纵向滚动但不出现横向滚动（矩阵除外）。
- 400% 缩放（1280 → 320 CSS px）等同 390 档验收，不额外设计。
- `prefers-contrast: more`：移除纸纹、`rule` 提升为 `rule-strong`、禁用状态 wash；`forced-colors` 下依赖边框与系统色，不覆盖 `ButtonText`/`Highlight`。
- 动效不承担语义：关闭动效后「部署中」仍由静态弧 + 状态词表达（第 9.4 节）。

重定向实现要点（wouter 3.10，`Redirect` 只接受字符串）：

```tsx
function Moved({ to }: { to: string }) {
  return <Redirect to={`${to}${window.location.search}`} replace />
}
// 新路由必须排在旧路由前；/network/chains/new 与 /chains/:id/edit 必须排在 /:id 前
<Route path="/network/chains/new" component={ChainEditor} />
<Route path="/network/chains/:id/edit" component={ChainEditor} />
<Route path="/network/chains/:id" component={ChainDetail} />
<Route path="/network/nodes/:id" component={NodeDetail} />
<Route path="/servers"><Moved to="/network/servers" /></Route>
```

- `:id` 必须是正整数，非法值直接渲染 404，不发请求；`/network/nodes/:id` 与 `/network/chains/:id` 不共用 id 空间。
- 旧页面文件在 P5 前不删除，用于就地回滚；P5 后删除 `Dashboard.tsx` 与 13 个旧页面 `*.css`，但保留 `chains/use-chain-form.ts` 的校验逻辑供编排器复用。
- 重定向只做一次，不链式跳转（`/logs` → `/run/logs/operations` 直接命中）；每次重定向在开发环境打点，P5 后移除。

### 11.4 设计系统治理

- **单一事实源**：`tokens.css` + 第 7 节表；`DESIGN.md` 当前仍是旧「红色索引标签 + 2px 直角」语言，P0 起标记为 deprecated，P5 重写为新语言，避免两份规范并存。
- **变更纪律**：令牌 PR 必须含对比度断言结果、两套外观截图、受影响页面清单、迁移说明；新增令牌需写明「角色 + 唯一职责」，禁止颜色名。
- **组件准入**：新组件先进 `components/kit/`，必须带 loading/empty/error/stale 四态与键盘说明；页面不得新写一次性控件（第 8.1 节）。
- **例外审批**：只有数据可视化可越过密度令牌；hex、px 圆角、`box-shadow` 字面量由 lint 脚本拒绝（第 7.6 节）。
- **废弃节奏**：`--cg-*` 冻结、只减不增；`--panel-accent` 作为 signal 的过渡别名保留一个阶段，P5 删除；不恢复任何主题注册表（`themes/` 目录当前已不存在）。
- **文档节奏**：每个 Phase 结束更新对应 `docs/design/part-*.md` 的「现状证据」与截图目录；发布说明记录令牌变更与新增组件。
