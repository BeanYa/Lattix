- 所有脚本以 `#!/usr/bin/env bash` 开头并启用 `set -euo pipefail` 严格模式，错误统一通过 `die "..."` 函数输出到 stderr 并退出。
- CI 发版时通过 sed 替换 `{{LATTIX_VERSION}}` 与 `{{GITHUB_REPO}}` 占位符，脚本中检测占位符未替换即报错中止。
- GitHub Release 下载的二进制必须附带 `checksums.txt` 或 `.dgst` 文件，使用 `sha256sum -c` 校验失败则直接中止，不降级跳过。
- 系统服务管理通过统一的 `use_systemd()` 函数判断是否走 systemctl，否则回退到 nohup/crontab 用户态模式，保持行为一致。
- E2E 脚本使用 `mktemp -d` 创建临时工作目录，通过 `trap '... rm -rf "$WORK"' EXIT` 清理，并在脚本内嵌 python3 单行程序操作 SQLite。
- CLI 参数解析采用 `while [[ $# -gt 0 ]]; do case "$1" in ... esac; done` 模式，缺失必需参数时调用 `die` 提示用法。
