本模块为纯 Bash 脚本集合，按职责划分为三类：
- 安装脚本：`install-panel.sh`（面板 native/systemd 或 Docker Compose 双模式）与 `install-agent.sh`（Agent + xray-core 三档运行模式：systemd / user / DEV），均通过环境变量与 CLI 参数驱动，从 GitHub Release 下载二进制并校验 checksums.txt/.dgst。
- 运维管理程序：`latx.sh`（面板侧 `latx` 子命令：status/start/stop/update/acme/cert/bbr/reset-admin/uninstall/version/help）与 `latx-ag.sh`（节点侧对称功能），两者通过 `use_systemd()` 函数统一判断是否走 systemctl，否则回退到 nohup/crontab 用户态/DEV 模式。
- E2E 测试脚本：`dev-e2e.sh` 为主入口，其余 `dev-e2e-*.sh` 分别验证 alerts、chains、event-log、links、panel-update、protocols、reconcile、settings、telemetry、tls、upgrade、usernodes、vlessenc、xray 等特性；每个脚本独立 build 后端与 Agent 二进制、用 `mktemp -d` 临时目录隔离状态、通过 python3 操作 SQLite 或 curl 调用 API 进行断言。
依赖方向单向：E2E 脚本 → 构建产物 → 面板/Agent 进程；运维脚本 → systemctl/journalctl/curl/python3；安装脚本 → curl/sha256sum/systemctl/crontab。所有脚本共享 `set -euo pipefail` 严格模式，并通过 `{{LATTIX_VERSION}}`/`{{GITHUB_REPO}}` 占位符由 CI release.yml 注入版本信息。
