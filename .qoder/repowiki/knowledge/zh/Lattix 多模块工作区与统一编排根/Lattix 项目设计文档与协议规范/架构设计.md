本模块为纯文档型 leaf，按职责拆分为多份独立 Markdown 设计文档与两份机器可读协议描述文件：
- `framework-design.md` 作为总纲，定义后端（Go+SQLite）、Agent（Go 独立二进制）、Frontend（Vite+React+bun）三层架构、单条 WS 长连接控制通道、离线命令队列与重发死信机制。
- `rpc-api-design.md` 约束 Panel↔Agent WS 信封与 Frontend→Panel HTTP RPC 的边界、状态码、统一响应信封与路由清单。
- `openapi.yaml`（OpenAPI 3.1.0）与 `ws-protocol.schema.json`（JSON Schema Draft 2020-12）是协议的机器可执行契约，分别描述管理 API 与 WS 消息结构。
- 其他专项文档覆盖子域：`billing-scheduler-design.md`（计费与定时任务器）、`chain-revisions-traffic-design.md`（链拓扑与流量统计）、`panel-lifecycle-state-machine-design.md`（生命周期状态机）、`server-probe-monitoring-design.md`（探针监控）、`logging-design.md`（日志系统）、`graceful-shutdown-agent-settings-design.md`（优雅关停与 Agent 设置同步）、`frontend.md`（前端实现约定）、`codegraph-analysis.md`（代码图分析）、`KNOWN_ISSUES.md`（已知问题）。
依赖方向单向：文档之间通过交叉引用（如 §6、§13、§17、§21）互相引用，无循环依赖；所有协议细节以 `rpc-api-design.md`、`openapi.yaml`、`ws-protocol.schema.json` 为准。
