根目录作为 Lattix 项目的编排中心：go.work 声明 agent/backend/shared 三个子模块，使它们共享同一份 toolchain（go1.26.5）并可互相引用；Dockerfile 采用三阶段构建——先用 oven/bun 编译 src/frontend 生成 dist，再用 golang:1.26.5-alpine 通过 go.work 一次性构建后端二进制并嵌入静态资源，最后以 alpine:3.22 镜像运行单一 lattix-backend 进程；install.sh 作为统一安装入口，根据 panel/agent 参数动态从 GitHub Release tag 拉取对应版本的 install-*.sh 脚本执行，确保发布产物与安装逻辑版本一致；scripts 目录集中存放运维与 E2E 验收脚本，docs 目录沉淀 RPC/WS 协议、OpenAPI 等契约，构成前后端与 Agent 之间的跨模块契约边界。
